# @tessera/tokens

Framework-neutral design tokens for color, spacing, typography and shape. Import `@tessera/tokens/theme.css` for CSS custom properties and `@tessera/tokens/fonts.css` for self-hosted variable Geist Sans and Geist Mono through an npm-aware bundler.

Themes use dark by default. Set `data-jl-theme="violet"` or `data-jl-theme="editorial"` on the area you want to theme.
